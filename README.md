# OurTeam - Group Portfolio Website

## About the Project

OurTeam is a simple and responsive group portfolio website developed using HTML, CSS, and JavaScript. It introduces our team of four engineering students, showcases their individual skills and responsibilities, and provides a contact page for project enquiries and collaborations.

The website is designed to be simple, user-friendly, and accessible on desktop computers, tablets, and mobile phones.

4. **Manish Kumar Kashyap** - Website Development and Responsive Design

## Website Pages

### 1. Home
- Introduction to the team.
- Overview of the project.
- Quick links to individual member profiles.

### 2. Individual Profiles
Each team member has a separate page showcasing their role, skills, and project contributions.

- Ankit Singh Thakur
- Anubhav Wadekar
- Shivam Tiwari
- Manish Kumar Kashyap

### 3. Why Hire Us?
- Highlights the strengths of our team.
- Explains our collaborative approach.
- Showcases our different areas of technical interest.
- Encourages project enquiries and collaboration.

### 4. Contact
- Contact form for project enquiries.
- Fields for name, email, project title, project type, and message.
- Basic form validation and confirmation message.

## Technologies Used

- **HTML5:** Structures the website content.
- **CSS3:** Handles styling, layout, and responsive design.
- **JavaScript:** Adds interactive navigation and basic form functionality.

No external frameworks or libraries are required.
